# Voice AI Agent Frontend

Next.js frontend for the Voice AI Agent, built with Pipecat Voice UI Kit and Tailwind CSS.

## Features

- Real-time voice interaction with AI agent
- WebGL plasma visualizer
- Live transcript overlay
- Audio controls
- Responsive design with Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Production

```bash
npm run build
npm start
```

## Environment Variables

- `AGENT_URL`: URL of the voice agent backend (default: http://agent:7860/api/offer)

## Tech Stack

- **Next.js 15** with App Router
- **React 19**
- **Tailwind CSS 4**
- **TypeScript**
- **Pipecat Voice UI Kit**
- **Three.js** for WebGL visualizations
